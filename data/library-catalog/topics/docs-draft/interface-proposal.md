## 1. LLM 接口约定（提案）

```python
def summarize_topic_region(region: dict) -> str: ...
```

| 项 | 提案 |
|---|---|
| 入参 `region` | `seed{id,term}` / `hops` / `decay` / `layers[{hop,nodes[{id,term,score,path}]}]` / `evidence[{mms,title,topics}]` / `stats{visited,edges_scanned,elapsed_ms}` |
| 返回 | `str`（Markdown 段落）。**不返回 JSON**——结构化数据由 CLI `--json` 通道给出，两者职责分离 |
| 环境变量 | `TOPIC_LLM=off`（纯结构化，不渲染）｜`mock`（**默认**，确定性模板文）｜`<endpoint>`（唯一允许触网的取值） |
| 硬约束 | ① **默认不触网**：未设置 env 时行为等同 `mock`；② `mock` 必须**确定性**（同 region 同输出，禁随机/时间戳）；③ **不得引入 region 之外的事实**（禁止模型自有领域知识、禁止对书目做推断） |
| 失败回退 | 任何异常 → 回退 `mock` 模板文 + stderr warning，退出码不变；`--strict-llm` 时以 exit 3 暴露 |
