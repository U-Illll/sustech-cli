## 0. 结论摘要

1. **复算完全对齐**：独立实现（自研 numpy BFS / 纯 Python BFS / scipy `breadth_first_order` 三条互校）在当前边表 + 400 源点(seed=42) 上复现报告 ①②③，**逐跳 12 个点、三个口径、次口径、可达数全部 abs_diff = 0.00e+00**。BFS 层语义、衰减 DP、连通分量均无误。
2. **计算缺陷确认**：覆盖率分子**排除源点**、分母**包含源点**。①因此有硬上限 `(csize-1)/csize`，实测上限均值 **0.920873**；观测 0.918799 已达自身上限的 **99.77%**。
3. **缺陷量级**：`1 − ①` = 0.081201，其中 **97.45%（0.079127）纯属该口径伪影**，真实未覆盖仅 0.002075（0.21%）。修正后 ① = **0.997925**（中位 1.000000），而非 0.9188。
4. **终审 0.8972→0.9763 成立但对象过期**：0.8972 是 **pre-R1 边表**读数（本审计逐位复现），非当前产物。该 4 位小数在 README / INTERFACE-PROPOSAL / acceptance-p3.log / meta.json 中作为裁定依据被反复引用。
5. **口径之争的根因是伪影量级差**：V0 下 ②(0.9912) > ①(0.9188) 使「改用 ② 当门槛」看似合理；但同一伪影在 ① 上扣 7.91pp、在 ② 上只扣 0.53pp（分母基数不同）。修正后 **①(0.9979) > ②(0.9964)**，排序反转，② 门槛的立论不成立。

## 2. 源点口径缺陷（核心）

`weighted_bfs` 在首跳前执行 `visited[src]=True`，源点**永不出现在任何 level**；而 `csize = members[cluster[src]]` **包含源点**。故 `cov = |可达\{src} ∩ C| / |C|`。
- 结构性后果：单点簇源点覆盖恒为 0；满覆盖上限 `(csize-1)/csize`，**①永远不可能到 1.0**。抽样 400 源点的 `mean(1/csize)` = **0.0791265**（csize 中位 17、均 23.8、max 101，含 1 个 csize=1 源点）。
- 变体敏感性（同一 400 源点）：

| 变体 | ① 主簇 | ② 主簇∪类目 | ③ 无向闭包 | ① 中位 |
|---|---|---|---|---|
| V0 现状（分子排除源点，分母含源点） | 0.918799 | 0.991155 | 0.920040 | 0.941176 |
| **V1 源点计入分子**（终审建议） | **0.997925** | 0.996419 | 0.999167 | **1.000000** |
| V2 源点同时出分母 | 0.994828 | 0.996396 | 0.996250 | 1.000000 |

  `V1 − V0` 恰等于 `mean(1/csize)`=0.079127（①③）与 `mean(1/usize)`=0.005264（②）——**伪影是分母基数的纯函数**，与本图质量无关。

- 三口径同一 BFS 域下 ② 的伪影被稀释：`usize ≥ csize`，故 ② 看起来「达标」而 ① 「不达标」。

## 4. 抽样口径

- `rng.choice(pool, ...)`：`pool` = kw 且 cluster≥0（4,838 个）。**节点均匀**抽样。
- 与 `graph_report.py` 并**不对齐**：后者是**簇均匀 + 每簇 1 源点**。同一张图、同一集合定义，仅换抽样框：V0① **0.918799 → 0.844938（差 7.39pp）**；上限 0.920873 → 0.855195。修正后 V1① 两框仅差 0.82pp。**即伪影把抽样框敏感性放大了 9 倍**，而 docstring 宣称「口径对齐 graph_report.py」。
- 抽样波动：独立 100 源点(seed=20260918) V0① = 0.908175，V1① = 0.988571（较 400 样本低 1.06pp / 0.94pp）；报告 400 中前 100 源点 ① = 0.907450，与独立 100 的 0.908175 仅差 0.07pp ⇒ **两个互不相干的 n=100 抽样彼此一致（±0.1pp），但相对 n=400 存在约 1pp 系统性偏移**；n=100 不足以支撑 0.1pp 级结论，验收应固定 n=400 或改用全量（`topics-report-exhaustive.json` 穷举 5,187 源点 ①=0.919449 印证该 1pp 偏移）。
- **RNG 流纠缠**：`srcs` → `perf_srcs` → `walk` 共用一条 `default_rng(seed)` 流。改 `--samples` 会移位 `perf_srcs`（400 vs 100 时 perf 样本重合度仅 0.02）⇒ 同一 `--seed` 下性能样本不可独立复现。

## 5. 口径歧义清单（建议的精确定义写法）

| # | 现状写法 | 歧义点 | 建议写法 |
|---|---|---|---|
| 1 | `coverage`: "可达节点中与源点同簇的比例" | 「可达节点」字面含源点，实现排除 | `C_h = {v : dist_dir(src,v) ≤ h, v ≠ src}`；`num = |C_h ∩ {cluster==c}|`；`den = |{cluster==c}|`；源点既不计入 C_h 也不从分母扣除 |
| 2 | 分母 "同簇节点总数" | 未说明是否随可达性收缩 | 明确为**全图静态簇基数**（与可达域无关），故 C_h 单调不减 |
| 3 | `same_cluster` "cluster=-1 源点丢弃并单列" | 只对源点生效；cluster=-1 目标节点仍留在分母 | 补：目标节点不因 cluster=-1 被排除，只是永不计入分子 |
| 4 | `definitions.bfs` "levels 与 graph_report.bfs_levels 等价" | 后者 `if not frontier: break` 会截断列表长度，前者恒返回 H 项 | 改为「**可达集合**等价；列表长度语义不同（topics 恒 H 项，graph_report 可提前截断）」 |
| 5 | ② "主簇∪类目" | 未定义 cls 码为空时的行为（实现退化为 ①） | 补：`cls 为空 ⇒ m_u = m_c`，并报告退化样本数 |
| 6 | ③ "无向闭包" | 实为 **≤H 跳无向 BFS**，非闭包；仅因本图 12 跳内全饱和才等价 | 改为「无向 H 跳可达域」，并**显式输出饱和率**（本图 100%）；或直接改为真闭包（整分量）并去除 H 依赖 |
| 7 | `decay` retention "vs_prev" | 实为**均值之比**，非逐样本留存率之均值 | 注明 `retention[h] = decay_mean[h] / decay_mean[h-1]`（比值之比，非平均留存） |
| 8 | `final_union.gate = 0.90` | ② 分母基数与 ① 不同，沿用同一门槛不可比（V0 下 ② 天然偏高） | 各口径门槛独立标定，或只对 ① 设门槛、其余仅作诊断列 |

## 6. 其他检查

- **连通分量**：独立并查集 = scipy `connected_components(A+A.T)` = 4 分量 / 最大 5,184 / 单点 3，**一致**。`A+A.T`(ones) 与 `A0.maximum(A0.T)`(max 权) 支撑集一致（无负权，故无 `w_uv+w_vu=0` 抵消风险）；但用 `A+A.T` 求连通而用 `maximum` 求 ③ 属**两套无向化**，建议统一并注释。
- **衰减**：hop1 得分 0.3058161299 = 最优路平均边权 0.3556001511 × 0.86（报告 0.3058161597，差 3e-8 为 float32 精度）。`theory_086 = 0.86^h` 与 `theory_wbar = w̄·0.86^(h-1)` 均为**参照线而非拟合**，标注正确。因 w∈[0,1] 且 DECAY<1，「同层取最大入路」等价于该层全局最优路径，**DP 精确**；但若出现 w>1 的边即失效，而报告对 `weights_above_1` **仅告警不拒收**——建议该情形下把 decay 口径降级标注。
- **性能计时**：无 warm-up（首次调用计入冷启动）；只计 `weighted_bfs`，**不含**每样本的簇/类目布尔掩码与父节点 `lookup` 构造。本机复测冷 p50 2.77ms / p95 4.18ms，预热后 p50 2.79 / p95 4.16，**噪声（±1.3ms）大于冷热差**，故 p95<300ms 结论稳健，但报告 p50=2.62/p95=3.31 的精确值不可复现（机器噪声）。
- **--json 字段**：三处问题——(a) `definitions.coverage` 与 `coverage.denominators` 四条**均未提源点处理**（歧义清单 #1）；(b) `final_union` 沿用 0.90 门槛（#8）；(c) `decay.per_hop[*].score_mean` 饱和跳写 `null`（hop 7–12），语义正确但缺 `null=已饱和` 的字段级说明，与 `samples_with_new_nodes=0` 需对照阅读。

## 7. 建议

1. **修口径（P0）**：分子改为 `(C_h ∪ {src}) ∩ C`（V1），或对称地 `den = |C \ {src}|`（V2）；二者均可，但**必须写死在 `definitions` 里并同步 README**。修正后 ① = 0.9979，门槛争议自动消失。
2. **重发文档（P0）**：README / INTERFACE-PROPOSAL / acceptance-p3.log / meta.json#stages.P3 中的 0.8972/0.9797/0.9200 三数标注为 **pre-R1 口径**，并补登当前表值 0.9188/0.9912/0.9200。
3. **③ 去伪（P1）**：输出无向饱和率；若恒为 100%，说明其为连通性统计量，不能用作调参反馈。
4. **抽样（P1）**：明确采用节点均匀还是簇均匀框架，并与 `graph_report.py` 对齐或声明差异；`perf_srcs` 改用独立 `default_rng`，与覆盖抽样解耦。
5. **回归防线（P1）**：把本节 3 组数字（V0 现状值 / V1 修正值 / pre-R1 溯源值）固化为 `report_audit.py` 断言，防止口径再漂移。
