## 1. 溯源：0.86 的出处与独立复算

**出处链（唯一）**：`~/go/reasonix-scripts/lib-catalog/TOPIC-GRAPH-HANDOFF-20260918.md:37`「语义衰减：1/2/3 跳余弦 0.730/0.636/0.584（随机基线 0.408）≈ **每跳衰减系数 ~0.86**」→ 同文档 §3.4:95「w_hop = w_parent × edge_w × 0.86（对齐实测衰减）」→ `topics_report.py:47 DECAY=0.86` → `topic_graph.py:65 DECAY_DEFAULT=0.86` → `README.md:367`、`topics_meta.py:153`「0.86 沿用 §3.4/v1 实测值」。**全链无一份计算记录，仅此一句"≈"。**

**候选推导式逐条复算**（输入 0.730/0.636/0.584，基线 0.408）：

| 推导式 | 值 | vs 0.86 | 四舍五入=0.86 |
|---|---|---|---|
| r21 = c2/c1 | 0.871233 | +1.31% | ✗ |
| r32 = c3/c2 | 0.918239 | +6.77% | ✗ |
| geo(r21,r32)（= loglin 拟合，两独立式同值） | 0.894427 | +4.00% | ✗ |
| c1^(1/1) / c2^(1/2) / c3^(1/3) | 0.730000 / 0.797496 / 0.835868 | −15.1% / −7.3% / −2.8% | ✗ |
| **c2^(1/3)（错位一跳）** | **0.859975** | **−0.003%** | **✓（唯一）** |
| 扣基线后比值 → 几何均 | 0.739313 | −14.03% | ✗ |
| r21 / geo（同口径 400 源点重跑） | 0.877333 / 0.898888 | +2.02% / +4.52% | ✗ |

**裁定**：① 「≈0.86」不可复现；最接近的有原则值是 r21 = **0.871**，唯一给出 0.86 的构造是把"2 跳值"当"3 跳值"用（错位一跳）或纯手工取整。② 输入三数本身不稳：同口径重跑得 0.750/0.658/0.606（比值 0.877/0.921），抽样波动 ±0.02–0.03 绝对量级——**"实测值"在两位有效数字上都不唯一**。③ 更根本：`graph_report.py:130-139` 显示这三数是**各跳节点与源点嵌入的平均余弦相似度**（v1 文档图边权本身就是余弦，`build_graph.py` 的 `knn_csr.npz/sims`），而 0.86 是**边权乘积上的额外乘子**——**余弦比值 ≠ 分数乘子，量纲不同**，迁移本身是类别错误。

## 2. 可辨识性：0.86 不是可测量量

实测 `score_0.86(h) / score_1.0(h)` 对 h=1..6 **恒等于 0.86^h**（相对偏差 ≤2.4e-16，探针 §C），即 `score_d(v) = Π(路径边权) × d^h` —— **d 是纯尺度因子，与边权 w 不可联合辨识**：任意 d 都能完美"拟合"同一批数据。故「0.86 是否等于主题图的真实衰减」**是伪问题**。d 唯一可观测的后果只有两条：(i) 分数绝对尺度；(ii) 在**冻结的绝对阈值 0.05** 下哪些节点被放行。真正可测且与 d 无关的图性质是 **纯比值 `ratio_pure(h) := mean_h(Πw) / mean_{h-1}(Πw)`**（§4 实测）。

## 6. 数值容忍标准建议（替代"衰减合理"）

- **R1（主判据，与 d 无关，可硬断言）**：`ratio_pure(h)`（decay=1.0 实测逐跳比值，h=2,3）∈ **[0.50, 0.70]**。实测 0.5928 / 0.5827 ✅；两独立样本波动 ≤1.3%，离带边界 ≥15%。带外（<0.50 过陡 / >0.70 不衰减）须查边权分布与 top-k 构造。
- **R2**：首跳均分（纯口径）∈ **[0.30, 0.45]**；现行含 0.86 口径下 ≥ **0.30**（实测 0.3556 / 0.3058 ✅）—— 保留终审既有条款①。
- **R3**：`ratio_pure(h) ≤ 1.05`（h=2..6），禁"假增长"；实测 hop4 = 0.9983 贴上限（平台期），**须标注为平台而非衰减**，不得当作"衰减达标"。
- **R4（禁用条款）**：① 不得把 `retention` 与 `0.86^hop` 理论线直接比（该线假设边权恒 1；现有条款④正确）；② **新增**：不得把 `effective_hop_factor` 列当衰减读数（§3 实测低估 22–57%）；③ hop ≥9 无新增节点视为正常饱和（保留）。建议把 R1–R4 与实测值写入 `meta.json#stages.P3.caliber_freeze.decay_tolerance` 与 `topics_report.py` txt 输出尾部（本任务只读主体，未改动）。

## 7. 是否应把 0.86 改为实测校准值？

**建议：不改数值，改定位与文档（零行为变更）；若终审要求"常数必须可复现"，则一次性替换为 0.894427。**

1. **不存在"实测校准值"**：§2 已证 d 与 w 不可联合辨识。实测 0.59/0.58 是**边权乘积**的性质（w 的衰减），不是 d 的；把 d 设成 0.59 只会把分数再整体压一遍，不产生任何"更真"的信息。
2. **0.86 确实无法溯源，但替换值同样任意**：若必须给读者可复算的数，唯一有原则的候选是 **0.894427 = sqrt(0.584/0.730)**（几何平均逐跳比 / 对数线性拟合斜率，两条独立式同值）。0.86 **落在可复现区间 [0.871, 0.918] 之外** —— 当前值既非实测、也非任一推导结果。
3. **改动成本**：放行节点 +5.0%（d=0.894）或 +18.8%（d=1.0）、层内 top-12 变动 1–7%、与冻结阈值 0.05 耦合；且阈值与 d 在不同跳数上不可分离，单一阈值**无法精确复现**原放行集，须按 R1 重新标定 → 必须重跑 P3/P4 并重冻口径，**收益（可溯源性）与成本不成比例**。
4. **推荐最小动作（本次未执行，只读主体）**：① `topic_graph.py:65` 与 `topics_meta.py:153` 的"0.86 沿用 §3.4/v1 实测值"改为「0.86 = **尺度约定**（非实测）；v1 文档图可复现的逐跳余弦比为 0.871–0.918（几何均 0.894），0.86 为该区间外的历史常数；与冻结阈值 0.05 联合生效，改动须重跑验收」；② `README.md:367` 及 HANDOFF 复述处同步，`ACCEPTANCE-REPORT.md` §7-⑥ 结论维持并补引本报告；③ 登记 §6 的 R1–R4，把"衰减合理"从定性改为定量。
